# 固定多环阶段1执行计划

本轮只落实[总体方案](fixed_terminal_reconstruction_plan_stage1.md)的阶段0定义与阶段1仿真基础，不执行后续算法研究。

1. **冻结问题合同。** 明确固定几何、容量、运动、资源、能源、外部准入、应急、有限正常候选域及指标。把合成假设和未建模动态写清楚。
2. **实现独立核心。** 在新固定终端区模块完成轨迹、可行性、场景、环境与输出。调度接口支持中间环等待和后续窗口，安全规则不依赖调度器。
3. **验证局部语义与输出。** 用针对性测试和小样本检查连续安全、容量、资源冲突、能源储备、应急判定、随机流独立性及全请求统计；修正实现错误时记录参数是否受影响。
4. **运行冻结场景。** 依照低/中/高负载和高/中/低 SOC 定义执行阶段1 pilot。保留所有失败与截尾，不按结果调整场景难度。无需增加算法比较矩阵。
5. **阶段1审查。** 检查高密度初态与持续需求是否在模型中可行、运营容量是否合理、能源约束是否过强或过弱、指标是否能解释拥堵与应急。报告合成假设的适用范围和观察到的问题。

审查完成后停止。只有研究问题稳定且获得后续任务授权，才制定阶段2传统调度基线方案；不自动启动优化、RL、IL、teacher、动态几何或硬件实验。

当前完成度见[当前状态](CURRENT_STATUS.md)。旧 I0–I2、PPO 和 M1–M4 顺序均不约束本阶段；历史数据继续保留，但不作为新模型通过验证的依据。

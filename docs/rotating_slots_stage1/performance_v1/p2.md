## Changes

`world._check_execution` builds each eligible aircraft's base trajectory once
in original aircraft order, then checks the original `combinations` order.
Zero or one body still performs no base construction and no pair query. The
mapping exists only within this call; `_base`, stable metadata, hashes,
minimum updates, UNKNOWN handling, failure bisection, energy advance, events,
and failure ordering retain their original operations.

`trajectory._intrinsic_bounds_from_polar` contains the unchanged intrinsic
velocity, acceleration and jerk expressions. `Segment.intrinsic_bounds` keeps
its signature and delegates to this pure helper. The helper reads the existing
jet's Interval endpoints and creates derived Intervals without mutating its
input. No derivative precomputation, Horner evaluation or precision change is
introduced.

Each `validate_plan.check` node derives velocity, acceleration and jerk from
its existing polar jet; each `_peak_measure` node creates one jet for velocity
and acceleration. Recursion, thresholds, cutoffs and algebraic operation order
are unchanged. No cache survives a node or physical interval.

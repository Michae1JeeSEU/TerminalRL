- 查看槽位 ID/相位及 FREE/RESERVED/OCCUPIED/DEPARTING；区分实际当前承诺、未来可编辑软计划及其依赖。
- 查看服务类别、SOC、应急标志、实际启动费用、六 pad 剩余服务时间；不要用 episode 最终指标冒充当前时刻指标。
- 选机检查速度、加速度、jerk、功率、SOC 日志；确认当前三维最近机对，以及明确标注的连续距离区间/见证时刻。
- 对解析包核对 `ANALYTIC FIXTURE` 标识；被拒候选只是诊断覆盖层。V08 失败和剩余飞机截尾必须保留，不当作正常完成。

人工观察写在 **bundle 外的独立文件**，例如 `D:\7_codespace\terminal\artifacts\rotating_slots\researcher_observation_f67b5c8_20261016.json`。记录观察人、时间、源码提交、case/包路径、`replay.json` 的 SHA-256、查看过的时刻/视图/控制、截图路径及逐项意见；未观察项保留 PENDING。可读取包索引 hash：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "$replays\V04\replay_00\replay.json"
```

不要直接修改带索引 hash 的 bundle 成员，也不要把自动 PASS 写成负责人认可。只有研究负责人实际观察后，才能在独立记录中填写其认可或问题意见；V12 状态需由后续明确的验收记录更新。

## 建模边界与接续

车辆/能源是性能约束点质量研究替代模型，不是完整 6DOF 或实机数字孪生；需求、SOC、服务和部分限制属于冻结研究假设。重建的 `energy_reference_v1_0.py` 来自合同附录，**不是缺失的原始参考程序，也不是独立实测 oracle**，详见 [来源与限制](sources.md)。
正式矩阵与后续分析按上面的运行记录继续，研究负责人完成观察后另行更新 V12。当前不宣布 94 项全过、正式性能结论或 `STAGE1_ACCEPTED`。接口和操作约定见 [API](api.md) 与 [qualification](qualification.md)。

# 阶段6：学习辅助联合调度方法

阶段6沿用阶段1–5固定物理、安全、能源和资源层，检验固定质量条件下的搜索成本。阶段5结论保留；本阶段正式结果尚未生成。

## 搜索和确定性提交

每次决策从当前已到达机群生成上限14的同一联合根候选池，使用固定93维特征与FCFS闭合评价J。复用阶段5冻结的MLP rank和gradient boost，不重新训练；manifest仍核对全部四模型hash。部署特征不含未到达draw、seed/profile/method标签或真实结局。

八个方法为beam_b3、beam_b5、beam_b8、full_reference、beam_adaptive、rank_adaptive、gb_adaptive和hybrid_adaptive。共同unique anchors包含在TOTAL预算内。四个adaptive方法先评估B3；学习仅改变第一轮排序，后续统一按完整beam顺序填充未评估根至B5、B8、full。每根闭合rollout只执行一次，后续复用该决策内缓存，所有已执行阶段成本累计，不跨方法共享缓存。hybrid沿用阶段5的beam/MLP交替顺序。

停止证书记当前已到达数A，已失败数F0，已应急着陆数E0。当前最优根闭合评价同时满足F=F0、E=E0、N=A−F0−E0、C=0时提前停止。这证明该有限闭合机群达到了正常完成数上界并且无新增失败或应急，不证明全部J分量最优，也不保证未来到达下的系统结果。历史失败与应急不能从分母删除；正在执行的应急承诺不计入E0。

未获证书则扩搜；全池耗尽仍未获证书时返回已评估根中的词典序最优，并明确记录未获证书。有限池耗尽不能解释为正常域不可行或安全保证。单根直接走确定性提交，不运行学习推理或闭合rollout，证书为null。最终提交的独立可行性验证和原应急层始终执行；搜索预算耗尽不能授权应急。

## 评价证据

完整episode比较实际请求结局、累计J和各自轨迹上的计算。独立同状态panel采用joint_window前缀，在t0/t60克隆同一环境；每个方法重新生成同一候选池并自行运行全部决策步骤。full结果仅在所有方法结束后作事后标注，单根所需闭合标注成本单列，不计入任一方法时间。

完整decision wall包含生成、特征、推理、所有新增rollout、最终验证与应急；模型冷加载、IO、环境推进分别报告。panel单worker且与episode阶段不重叠；episode允许独立场景多核并行。并发轨迹墙钟不作为同状态加速或实时性证据。

## 结论边界

质量条件和10%计算门槛预先冻结于[协议](../experiments/fixed_terminal_stage6_protocol.md)。三种学习方法分别与B3/B5/B8/full/beam_adaptive比较，不能择优隐藏参考。学习贡献必须通过同机制beam_adaptive比较；adaptive机制自身有效不等于学习有效。A/B/C判断留待实际结果，单一模型训练seed及有限池FCFS闭合值不支持训练稳定性或长期Q结论。

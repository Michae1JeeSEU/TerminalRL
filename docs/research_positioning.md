# 研究定位：固定多环联合到达调度

在随机剩余电量和持续到达需求下，联合安排多 UAV 各环等待、向内跨环转移、最后进近与 pad 服务窗口，在独立的安全、能源和资源约束下提高正常着陆效率并控制应急代价。

阶段1建立了内部一致的合成仿真。阶段2冻结实验已经完成，其研究问题是：**在物理合同完全不变时，传统排序、联合窗口与滚动优化可以取得怎样的服务结果与计算代价？**

## 阶段2比较内容

SOC 排序表示当前电量紧迫性；能源余量以真实可行普通计划的最低能源加储备为基准；deadline slack 以最后可行正常完成窗口为基准。三者不能互相替代。候选搜索截断时，只能报告未知或已知上下界，不得把零等待路线冒充可行最小值。

联合窗口选择多架飞机之间相容的完整路线窗口。滚动方法在可观测当前状态上模拟未来推进及 HOLD/延后选项，只承诺第一批完整计划；它不能读取生成器已采样但尚未到达的请求。所有方法使用相同的独立可行性与应急资格规则。

小规模 SciPy MILP 仅在明确有限候选目录和目标下提供参考。算法与 oracle 使用同一目录，所有结果按共同评价目标重算差距，而规则优先级和rolling内部surrogate保持各自定义；独立检查解可行性，求解受限与 OPTIMAL 必须区分。该结果不能宣称原始全动态问题的全局最优。

## 结论边界

冻结阶段1几何、容量、能源、SOC分布和负载，不为提高方法结果调整难度。完整报告全请求正常、应急、失败、截尾、时间、能源与计算结果，并区分成功子集条件均值。保留弱结果与搜索未知。

模型采用合成归一化能源和圆弧/直线运动学，未建模加速度、实际控制器跟踪和外部空间轨迹。阶段2可比较给定模型下的方法表现，不支持硬件安全认证、真实流量适用性或未验证的学习必要性结论。本轮主审结论为学习必要性尚未建立，不将结果强行归为计划中的学习方向2/3/4，不启动第三阶段训练。

## 阶段2证据判断

162场和12个有限目录参考全部完成，详见[结果报告](evidence/fixed_terminal_stage2/results.md)。FCFS正常444/失败7，deadline445/7，joint429/9，rolling441/9。rolling相对joint正常增加12，但相对FCFS少3正常、多25应急、多2失败、少24截尾，存在结局权衡；其632/1296次决策超过5 s。正常延迟是完成者条件指标，不据较小均值推断整体改善。

SOC排序不等于有效的可行性紧迫程度，slack规则也未稳定超越FCFS；这不表示能源不重要。高负载积压与低SOC失败需要共同观察，但负载档的初始占用和到达强度同时变化，各类空间资源又耦合，不能作单因素归因。

联合与滚动采用不同冻结评分，不能把二者差异单独归为未来影响。有限目录最优不代表全动态最优；当前Python并发耗时不代表传统优化固有下限。离线仿真没有把真实计算等待计入交通时钟，不能据服务结局宣称在线部署能力。尚未排除更好的传统目标、候选覆盖或实现，不能用本轮比较证明必须采用学习近似器。

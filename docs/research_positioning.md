# 研究定位：固定多环联合到达调度

研究问题是：固定终端区内，面对持续随机到达和随机剩余电量，如何联合安排多架 UAV 的向内跨环转移、最后进近与 pad 服务窗口，在安全间隔、轨迹可执行性、容量、服务资源和最低储备约束下提高正常着陆效率，并控制应急代价。

研究对象是有限空间与时间资源下的多机协调。允许调度器选择各环等待时间及后续窗口；仅给出初始放行排序不足以表达这个问题。几何和容量定义对全部后续方法相同，不作为调度动作。

## 阶段1回答什么

阶段1建立明确的问题合同、独立可行性层、可复现场景生成器和全请求指标，检查固定几何能否支持低、中、高负载，以及不同 SOC 分布下的正常、应急与失败结果。用于驱动仿真的简单可行调度仅是测试工具，不能据其性能宣称传统方法上界或提出算法创新。

安全、能源和资源规则由确定的可行性层执行。后续调度器可优化服务窗口的选择；是否加入学习方法，要在后续阶段的独立研究决定中判断。阶段1不需要 RL 成功、teacher 或旧 qualification。

## 结论边界

本模型采用合成固定几何、归一化分模式能耗与有界运动学轨迹。可主张的是模型内部的约束一致性、可复现性与给定参数下的运行现象。尚无实机能耗标定、空气动力学验证或真实城市到达数据支持，不能把这些合成参数称为真实运行域或硬件安全认证。模型不显式求解加速度动态，轨迹可执行性只指已声明的速度、下降率等运动学界限。

效率和能源结果必须与失败、应急、外部积压及观察截尾一同报告，不能只展示成功降落子集。参数在 pilot 前冻结；发现问题时如实记录，不通过结果反向选择场景。

# 固定终端区联合调度学习问题定义

状态：**阶段3定义与机制实验已完成，学习必要性仍未证明。** 本文定义一个可检验的候选接口，不开展模型、训练或teacher构造。依据[阶段3协议](experiments/fixed_terminal_stage3_protocol.md)，原[物理问题定义](fixed_terminal_problem_definition.md)继续冻结。

## 事实基础与待检验对象

阶段2FCFS正常444/失败7，deadline445/7，joint429/9，rolling441/9。rolling相对joint正常+12但不支配FCFS，且两者评分不同。阶段2没有证明学习必要性，用户计划开头关于joint/rolling有效和传统边界的表述不能视为已证明事实。

阶段3要检验的是：在同一可观测状态、给定其他已选候选和固定continuation时，一个完整服务窗口或联合批次对应怎样的系统有限窗价值。现有独立策略rollout决策差异仅用于定位机制案例，不能代替同状态一次干预的配对结果。

## 状态与输入边界

允许输入当前时刻及所有已到达请求的信息：每机state、SOC、ring、theta、arrival/admission时间，已到达外部队列；固定geometry、资源及reservations；完整既有commit。终态记录与已有累计指标按声明的状态合同保留，不能把active数当作全部观测容器大小。

禁止输入尚未到达请求的抽样身份、SOC、时间，完整未来路径、全程结果标签或方法来源label。离线ex-post结果只能用于机制核对，与部署输入明确分离。`observed_clone`负责删除未到达信息，具体机制接口见[技术规范](technical_spec.md)，正式产物的信息隔离与分母已核对；本阶段不设计GNN、attention或网络结构。

## 候选动作与输出

`a_i`为给某机一个规范完整窗口，用`wait_cycles`表达各环等待及随后的跨环、进近、pad预约。`A`为联合普通计划批次。候选由原确定性生成器给出；独立feasibility决定是否可行，execution负责提交和推进，安全责任不交给预测值。

承诺/预约时刻不是实际释放时刻；有额外等待圈的候选可立即承诺而较晚离环。离环时刻应从Plan首个非hold段start读取，完成时刻另记，不能以commit event.time解释谁提前释放。

后续可研究的学习接口是**受约束单窗口的条件价值或联合批次价值评分**，后续仍与确定性候选生成、独立可行性和执行层衔接。它不是自由飞行动作，也不是把飞机按一个固定priority排序。已有完整承诺不撤销，未选飞机保持，所有方法共用应急资格。

## 可检验价值

词典序最大化`J_H=(-F,N,-E,-C,-T,-D,-energy)`：分别为实际能源失败、实际正常完成、实际应急完成、已到达未终态请求、全部观察暴露、正常延迟总和、全部实际能源消耗。`not_arrived`不计C；尚未完成的预约不计N/E。保存原始分量和正常完成者条件均值，不人为拟合权重奖励。

selection comparison key在正式运行前冻结：前四计数精确整数，T/D各round至8位小数，energy SOC round至10位；raw J/ΔJ保留。no-worse使用同一key；同key按由aircraft_id与wait_cycles排序得到的`action_key`最小者确定性tie。不得将微小浮点残差解释为系统收益，正式运行后不按结果更改口径。

这是给定continuation和有限终点的模拟量，不称为optimal Q、期望Q或真实无限期价值。根批次相对HOLD的分量差为`ΔJ(A;H)=J_H(A)−J_H(HOLD)`，另报告相对FCFS根差分。单机边际必须条件在其余批次B：`ΔJ(a_i|B)=J(B∪{a_i})−J(B)`；两批都可行才有定义，否则返回undefined及可行性状态，不假定各机价值可加。

协议固定15个依阶段2结果选择的context、最多19个root、FCFS continuation和20/60/until240三种终点。J原始分量均从episode起点累计，保留共同FCFS prefix；t60历史项在Δ中抵消，不另定义增量J。输出`root_time/evaluation_stop/episode_cumulative=true`。这个样本集不是heldout测试，也不是teacher训练数据；三个t60状态无holding且仅有空HOLD根，12个t0才有多候选。

## 标签与机制核对

闭合观测估计只含根时刻已到达请求（包括已终态历史），评估三个终点并在同一root池选择。ex-post则在完整固定原需求路径上执行同一次root干预，再统一FCFS至240 s；政策仍只看已到达状态。二者分别保存`request_count/arrived_count`，不能跨世界直接作同分母性能比较；不把真实未来偷渡成输入，不把闭合估计当成真实期望标签。

扩大候选与beam、延长窗口只产生预算受限参考。t0六控制根是已保存决策的warm-start且已独立验证；t60六根在共同FCFS状态重算，计时按协议分项报告。remove-one只对参考根中ID最前至多3个plan进行，两批可行才定义条件边际。

## 机制结果与最终定义边界

15个机制context已完成，209个唯一根全部保留，15个FCFS实际逐请求结果与阶段2一致，57测试通过。状态、J/Δ、选择和两世界分母已核对，执行spacing违反与未认证均0。完整结局、成本、原始分量入口见[阶段3结果](evidence/fixed_terminal_stage3/results.md)。这仅验证给定合成模型，不能外推硬件安全。

三窗选根不同10/15；实际词典序相对FCFS的赢/平/输为20s 0/12/3、60s 5/7/3、until240 6/8/1。until240相对60s仍有1例退化；词典序win也不等于Pareto收益。low/low101以应急减少1换来截尾增加1、暴露增加203.3996939 s。high/low101的闭合SOC根优于FCFS，却在相同实际未来下少2正常、多1应急和1截尾，排序反转。不能盲目蒸馏闭合参考，也不能把当前标签称作期望未来价值。

33次局部remove-one中13可行、20因去除后的连续间隔不可行而undefined；这些取所选根前3ID，非全候选统计。批次可行性和价值不能默认可加，undefined不能转成0或负奖励。

较强预算传统参考产生局部改进，也有负结果；它不是传统上界或全局优越方法，学习必要性仍未证明。后续输出可为明示continuation、horizon与需求假设下的结果分量向量或批次比较分数，安全仍由独立层决定。若未来研究期望未来价值，须另定未来需求模型和独立需求路径，不能直接使用本轮闭合标签代替。当前成本只提供快速估值动机，不证明学习唯一必要。本阶段不训练actor、PPO、IL/teacher或任何网络，不调奖励，也不自动进入下一阶段。

# 固定多环终端区联合到达调度研究重构计划：阶段5

## 阶段4审查结论

阶段4完成了第一次学习型调度验证。

核心结论：

1.  存在可学习的候选排序信号。
2.  但是学习方法尚未证明优于同预算传统搜索。
3.  学习必要性仍未成立。
4.  当前最重要的问题不是继续扩大网络，而是明确：
    -   学习是否应该作为搜索加速器；
    -   学习是否能够提供传统搜索无法获得的长期价值。

------------------------------------------------------------------------

# 阶段5目标

阶段5不直接扩大模型。

目标：

> 建立一个公平、严格的学习辅助调度比较框架，判断学习方法是否具有真实研究价值。

------------------------------------------------------------------------

# 阶段5原则

禁止：

-   PPO；
-   multi-agent RL；
-   teacher imitation；
-   端到端控制；
-   修改物理约束。

学习仍然只负责：

-   候选筛选；
-   价值估计；
-   搜索加速。

------------------------------------------------------------------------

# Step 5.1 分析阶段4失败原因

目标：

回答：

为什么rank有排序能力，但是没有整体优势？

重点分析：

## 1. 排序准确率与系统收益关系

检查：

rank预测正确时：

-   是否真的提高正常完成？
-   是否减少应急？

rank错误时：

-   是否造成严重退化？

------------------------------------------------------------------------

## 2. beam为什么仍然强

分析：

beam保留策略：

-   是否因为候选池太小？
-   是否因为anchors作用？
-   是否因为问题本身搜索空间不大？

------------------------------------------------------------------------

## 3. value为什么失败

分析：

-   标签噪声；
-   continuation偏差；
-   batch耦合。

------------------------------------------------------------------------

目标：

评价：

同质量下减少计算。

## 方向B：批次价值预测

目标：

预测完整联合方案价值。

解决：

不可加问题。

------------------------------------------------------------------------

## 方向C：长期价值模型

只有当未来需求模型明确后考虑。

不能直接使用阶段4标签。

------------------------------------------------------------------------

# Step 5.3 建立公平计算预算实验

比较：

## 传统

-   beam不同预算；
-   rolling不同窗口；
-   full_reference。

## 学习

-   rank筛选；
-   value筛选；
-   hybrid。

统一：

-   候选池；
-   精确验证次数；
-   CPU环境；
-   完整计算时间。

------------------------------------------------------------------------

# Step 5.4 扩展学习模型前的必要实验

优先：

## 简单模型

-   linear ranking；
-   MLP ranking；
-   gradient boosting。

目的：

判断是否存在结构化学习信号。

如果简单模型有效，再考虑：

-   GNN；
-   set encoder。

------------------------------------------------------------------------

# Step 5.5 建立论文级评价

必须报告：

## 性能

-   正常完成；
-   应急；
-   失败；
-   延迟。

## 计算

-   完整在线时间；
-   rollout数量；
-   搜索规模。

## 泛化

测试：

-   SOC变化；
-   负载变化；
-   不同初态。

------------------------------------------------------------------------

# 阶段5结束判断

## 情况A

学习不能超过beam：

结论：

学习不是必要方法。

研究转向：

更强优化算法。

------------------------------------------------------------------------

## 情况B

学习达到beam性能且明显降低计算：

形成：

学习辅助联合调度方法。

------------------------------------------------------------------------

## 情况C

学习超过有限搜索：

进一步研究长期价值。

------------------------------------------------------------------------

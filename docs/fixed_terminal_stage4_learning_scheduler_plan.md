# 固定多环终端区联合到达调度研究重构计划：阶段4

## 阶段3审查结论

阶段3完成了从"是否需要学习"到"学习问题如何定义"的转换。

核心结论：

1.  学习必要性尚未被证明。
2.  不能直接学习priority。
3.  如果引入学习，学习对象应是：
    -   条件窗口价值；
    -   联合批次调度价值；
    -   或昂贵滚动搜索的近似价值。
4.  安全、能源可行性和候选生成仍由确定性模块负责。

因此阶段4进入：

# 学习型调度方法设计与验证

但目标不是证明RL有效，而是验证：

> 在固定终端区联合调度问题中，学习方法是否能够以更低在线成本逼近传统优化方法。

------------------------------------------------------------------------

# 阶段4原则

## 保留确定性调度框架

学习模型不能替代：

-   轨迹生成；
-   安全检查；
-   能源可行性；
-   容量约束；
-   pad预约。

学习模块只负责：

-   候选价值预测；
-   调度选择排序；
-   搜索加速。

------------------------------------------------------------------------

# Step 4.1 冻结学习接口

首先确定：

## 输入

只能使用部署时可获得的信息：

-   当前飞机状态；
-   SOC；
-   已到达请求；
-   当前资源占用；
-   已承诺计划；
-   候选窗口特征。

禁止：

-   未到达未来需求；
-   完整未来轨迹结果；
-   方法标签。

------------------------------------------------------------------------

## 输出

候选动作评分：

例如：

candidate_value(a)

或者：

batch_value(A)

不能输出：

-   直接速度控制；
-   直接轨迹；
-   安全动作。

------------------------------------------------------------------------

# Step 4.2 建立学习数据生成机制

不使用原teacher。

数据来源：

传统高质量求解器：

-   rolling horizon；
-   beam search；
-   CP-SAT小规模oracle。

生成：

状态：

s

候选：

a

结果：

J(s,a)

形成：

价值学习数据。

------------------------------------------------------------------------

# Step 4.3 选择学习范式

比较三类方法：

## 方法A：监督价值学习

目标：

预测：

ΔJ(a)

优点：

-   稳定；
-   易分析。

------------------------------------------------------------------------

## 方法B：learning to rank

目标：

排序候选：

a1 \> a2

优点：

适合调度。

------------------------------------------------------------------------

## 方法C：offline RL

目标：

学习长期价值。

只有当存在明确未来需求模型后考虑。

------------------------------------------------------------------------

# Step 4.4 建立传统搜索+学习加速框架

推荐第一版：

不是替代rolling。

而是：

rolling search

↓

learning scorer筛选候选

↓

少量精确验证

↓

提交计划

比较：

-   完整搜索；
-   学习筛选搜索；
-   简单规则。

------------------------------------------------------------------------

# Step 4.5 评价

重点：

## 性能

-   正常完成；
-   应急比例；
-   延迟；
-   能耗。

## 接近程度

相对：

-   rolling；
-   oracle。

## 计算

完整在线链：

-   候选生成；
-   网络推理；
-   精确验证；
-   决策时间。

------------------------------------------------------------------------

# 阶段4实验顺序

## 第一步

不训练复杂网络。

先做：

-   handcrafted feature；
-   简单MLP；
-   ranking模型。

验证：

是否存在可学习信号。

------------------------------------------------------------------------

## 第二步

如果有效：

再考虑：

-   GNN；
-   set encoder；
-   attention。

------------------------------------------------------------------------

## 第三步

如果长期价值明显：

再考虑：

offline RL。

------------------------------------------------------------------------

# 阶段4禁止事项

禁止：

-   直接PPO端到端控制；
-   teacher imitation；
-   让网络输出不可验证动作；
-   用奖励替代物理约束；
-   使用未来信息。

------------------------------------------------------------------------

# 阶段4完成后的判断

## 如果学习不能超过简单搜索

采用：

传统优化+加速方法。

------------------------------------------------------------------------

## 如果学习接近rolling但速度明显提升

形成：

学习辅助调度器。

------------------------------------------------------------------------

## 如果学习发现传统搜索无法表达的长期价值

进入：

长期价值学习研究。

------------------------------------------------------------------------

# 后续暂不涉及

仍不研究：

-   动态空域；
-   自由飞行；
-   有限感知；
-   多智能体通信。

这些必须建立在固定空域联合调度已经解决之后。

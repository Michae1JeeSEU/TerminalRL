# 阶段5结果：筛选信号增强，但尚未证明学习主线必要性

阶段5已按冻结范围完成。固定状态有限候选池中，学习排序的保优率高于同预算beam；部分在线方法也增加了正常着陆数和词典序胜场。但这些方法出现了额外能源失败，完整在线成本没有下降，同状态计时也没有提供显著加速证据。因此，当前结果尚未达到“系统质量不退化且显著降算”的B类证据，也没有期望长期价值的C类证据。这个混合结果不等于学习完全无效；保守地不升级学习主线，继续保留beam B5/B8/full作为工程参考，rank与GB保持实验性。

## 数据与比较口径

正式评价包含330个episode（11方法×30场景）、30个snapshot生成任务、90个base contexts、9个大池contexts、24个同状态计时面板（264行）及9个continuation诊断。每方法有27个standard场景、915个请求，加3个medium/medium初相旋转场景、95个请求，共1010请求。分load、SOC、standard和initial_rotated是不同切片，不能跨轴相加。初相变体只覆盖3场，不代表广泛几何或分布外验证。

N/E/F/C分别为正常完成、应急完成、能源失败、已到达但未终态。240s内全部请求均已到达，N+E+F+C覆盖每方法全部1010请求。正常条件延迟按所有正常完成者的delay总和除以N，不能平均episode均值。累计目标为 `J=(-F,N,-E,-C,-exposure,-normal_delay_sum,-energy)`；前四项整数精确比较，exposure/delay按8位、energy按10位比较，相同key依照既定action_key。配对胜负优先比较F，不能只凭N增加判胜。

完整来源为正式根目录下 `summary/summary.json`（SHA256 `776fdfd89ad7220eea5f92c4bb764f4b5332fb7c24840b72740d0a99fe87b57b`）。[紧凑JSON](results_summary.json)保存客观数值、执行来源、模型及测试记录；[分组CSV](results_by_group.csv)保存全部11方法在all、standard、initial_rotated以及all范围load/SOC切片上的计数、正常加权延迟、暴露、能耗与成本。原始source_commit按实际运行记录保留，不改写为最终文档提交。

## 两项诊断没有提供足够对照

9个pool_limit32、t15 contexts实际为7个单根、1个8根、1个9根。逐场比较保存root IDs后，九个扩大上限池与各自base14 t15集合完全相同。因此本轮并未真正测试更大候选池，不能据此断言候选池大小不是限制因素。

9个continuation场景的旧beam/rank/value/full/HOLD选择并集均只有HOLD一个根，pair_count全部为0。这不是“观察到零反转”，而是没有可比较根对，不能识别continuation排序敏感性。closed与realized两个世界的请求分母按low/medium/high分别为7→9、15→25、23→48；N或J的跨世界变化不是策略收益，也不是期望Q。保留的原始values在紧凑JSON中，未将两个世界混成同分母比较。

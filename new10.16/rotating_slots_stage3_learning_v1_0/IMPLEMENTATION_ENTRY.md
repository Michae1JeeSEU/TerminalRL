# Stage3正式实施入口

先读`stage3_learning_initial_contract_v1_0.md`和`stage3_learning_config_v1_0.yaml`。D1—D7已批准，不再次询问；本包是实施规范，不含已完成算法、训练权重或实验结果。

## 执行顺序

**S3-A**：核对实际仓库与工作区，记录Stage2目标、候选空间、物理/应急/失败规则。生成真实运行绑定与resolved配置，隔离当前试验版本。新增薄适配器，拆开`WorkDescriptor`和昂贵物化，保留OFF原路径。通过版本、只读、目标一致性和事务测试。

**S3-B**：建立廉价关系特征、事实日志、数据血缘、开发资料和独立split。复用既有合法初态，不重新设计流量/SOC/服务。先用假模型和离线shadow证明接入；真实特征不能调用本应省下的昂贵计算。按配置收集有限参考，不把UNKNOWN/未尝试/未选中标负，不把CP当全局oracle。

**S3-C**：只训练一个CPU集合MLP，采用固定配置。正式训练与开发拟合权重隔离；使用validation选择checkpoint，test只能在模型冻结后打开一次。标签不足时交付DATA_INSUFFICIENT，不扩大预算或改成在线RL。

**S3-D**：同快照运行参考额度传统、半额度传统、半额度学习；然后仅在预先选定中等test根做两组60秒成对闭环。网络不改CP目标，不删KEEP/WAIT和承诺，不绕过最终验证。报告完整在线时间、真实昂贵调用及质量向量，复用本地可视化。

## 额度和停止

新增自动化总wall最多4小时，分阶段上限在YAML中；累计3小时45分钟停止新增计算，剩余15分钟归档。恢复不清零，不能自动追加600秒实验、多seed矩阵、第二轮训练或改网络至获胜。计算时限不足时保存到共同已完成边界并如实报告。

## 应交付的实现结果

真实绑定与环境锁、接口映射、12项针对性检查结果、原始事实和派生标签分离的数据索引、split、模型卡、训练曲线、同状态对照、60秒结果或部分完成原因、可视化入口、FINAL_REPORT.md。分开回答基础架构是否可用、是否有可学习信号、是否有完整在线收益。

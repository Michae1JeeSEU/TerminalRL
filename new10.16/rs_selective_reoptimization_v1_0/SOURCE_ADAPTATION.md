# 文献与代码借鉴记录

合同：FT-RS-SELECTIVE-1.0。本文区分已核对的材料与本合同的新设计；没有编译、运行或复制外部算法代码。

## 1. MAPF-ML-LNS

来源：Huang等，AAAI 2022，DOI 10.1609/aaai.v36i9.21168。论文第4节说明从若干agent集合中选择重规划集合；公开仓库 `hta1996/LNS-ML`，读取提交 `994e958bb345ac6b6b045c4e5984e8e79e0f394d`。

实际查看 `MAPF-ML-LNS/src/LNS.cpp` 中 `run()`：测试路径构造`neighbor_set`、提取邻域特征、按`model_weight`线性评分并排序，之后对选中的邻域删除工作副本中的路径、局部重规划。另查看agent特征与归一化代码。深模型有关代码有注释段，不能把注释原型称作默认在用的GNN。

本合同借鉴：少量便宜集合提案、集合级评分、只求解所选子集。B采用最多6组、共享场景编码和一次批量评分，是本项目设计，不是论文原参数。论文静态初始完整解、网格冲突和代价定义不适用本项目。真实已承诺飞行轨迹不得像搜索副本中的路径一样先删除。

## 2. Neural LNS for MIP

来源：Sonnerat等，arXiv:2107.10201v3。实际阅读图1与第3节，核对解除部分变量赋值、固定其他变量、调用传统子MIP求解器的流程；本轮未审查其完整公开代码。

本合同借鉴：`replan_ids`是“开放哪些变量”的正式接口。不同之处：本项目并不总有全机最终安全落地的完整可行解；FOLLOW仅是已知续飞，不证明能源无限可持续。因而不得援引子MIP含旧完整可行赋值的条件来宣称本项目递归可行或闭环单调改进。

## 3. BALANCE

来源：Phan等，AAAI 2024，DOI 10.1609/aaai.v38i16.29701。实际阅读算法1、两层bandit图和规模选择部分。公开仓库 `thomyphan/anytime-mapf`，读取提交 `47bb25e9ba58b22172e1531cb26f25af8a4531e9`。

实际查看 `src/LNS.cpp` 与 `src/BasicLNS.cpp`：搜索循环选择destroy策略及规模；工作路径表暂移除邻域路径；修复后更新启发式/规模统计；规模候选在此代码中采用2的幂，更新使用其自身MAPF成本逻辑。

本合同借鉴规模可调，不把“高负荷必选更多对象”写死。C的{4,8,12}、真实总成本与期限筛选是新设计。不能把论文标量收益、不安全中间路径或其特定bandit更新公式直接移植为本项目授权逻辑。

本合同借鉴关键种子和资源阻塞扩展。能源紧迫、机会、审查年龄和实际进展年龄是本项目新特征；它们不是论文规定，也不构成物理安全证明。

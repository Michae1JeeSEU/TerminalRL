## 关键结果 (5 UAVs, 400步, 20 episodes)

| 指标 | PPO (shared-action) | Heuristic |
|------|---------------------|-----------|
| Landed | 23.8 | 30.0 |
| Failed | 1.5 | 0.0 |
| Wait | 52.5s | 62.8s |
| Energy | 70991 | 87869 |
| Conflicts | 24.4 | 0.0 |

PPO 达到启发式 79% 着陆率，能耗降低 19%，等待时间缩短 16%。
主要差距：24.4 冲突（shared action 导致所有 UAV 同时向内收敛）。

## 核心发现

1. **稀疏奖励问题**：多 UAV 下 DESCEND 需要 ~60 步连续执行才能获得 landing bonus，随机探索概率 (1/3)^60 ≈ 10^-29，几乎不可能自然发现
2. **Progress 奖励的位置依赖性**：如果 progress 基于绝对位置而非增量/状态，agent 会学会"下降一段后 hover 不动"
3. **解决方法**：progress reward 仅在 UAV 处于 DESCENDING 状态时生效，迫使 agent 持续下降
4. **初始分布的重要性**：真实的初始状态分布（UAV 分散在各环，随机电量/等待时间/状态）是后续 Phase 5 HRL 训练的基础，确保 agent 面对的是接近真实情况的场景

### 着陆点占用机制

**需求**：着陆点不能同时被多架 UAV 使用，需在着陆后一段时间内占用。

**实现**：
- [x] `config.py`：新增 `MISSION_TYPE_LZ_OCCUPANCY` 定义 4 种任务类型及对应 LZ 占用时间
  - standard (30s), cargo (120s), emergency (10s), surveillance (60s)
- [x] `UAV`：新增 `mission_type` 属性，spawn 时随机分配（权重 45/25/10/20%）
- [x] `TerminalAreaEnv`：LZ 占用追踪 + 预留机制
  - `lz_occupied_until` 数组：记录每 LZ 剩余占用时间
  - `_lz_reserved_by` dict：记录每 LZ 被哪个 UAV 预留（防止多 UAV 竞争同 LZ）
  - 降落开始时预留 LZ → 着陆后转为占用计时器 → 计时结束释放
  - UAV 中止下降/被移除时自动释放预留
- [x] `_parse_low_level_actions`：LZ 被占用或预留时强制 CIRCLE
- [x] 观测新增 LZ 占用状态：`_local_obs_dim` 69→75（+6 维 LZ occupancy）
- [x] 全部 39 测试通过

## 设计决策

1. **环轨道锁定**：UAV 盘旋时强制锁定在环预设轨道 (R_i, H_i)，下降穿越环边界后若被要求盘旋，立即吸附到新环轨道
2. **LZ 预留机制**：UAV 开始下降着陆时即预留 LZ（而非着陆后），防止多 UAV 同时飞向同一 LZ
3. **预留清理**：UAV 死亡/移除/中止下降时自动释放 LZ 预留
4. **任务类型影响**：不同任务类型决定 LZ 占用时间，使空域管理更精细化
5. **观测维度扩展**：LZ 占用状态加入观测，策略可学习避开繁忙 LZ

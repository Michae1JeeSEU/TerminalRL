# 开发日志 2026-05-19

## 完成事项

### 1. 初始间距保证

**问题**：之前 `random_position_on_ring()` 独立随机角度，N=30 时约 10-15% 概率产生同环初始间距 < 10m，导致早期碰撞。

**修改**：
- [x] `uav_manager.py`：新增 `_find_safe_angle()` 方法，拒绝采样（200 次）+ 最大间隙回退策略
- [x] `_spawn_one()`：新增 `ensure_separation` 参数，初始生成时启用
- [x] 确保新生成的 UAV 与同环已有 UAV 的弧间距 ≥ `safe_separation`

### 2. CIRCLE 速度控制动作

**用户需求**：盘旋时增加速度控制自由度（0.3~1.3 倍环速），结合距离惩罚机制让 RL 学会主动拉开间距。

**修改**：
- [x] `wrappers.py::PerUAVDiscreteWrapper`：动作空间从 `MultiDiscrete([2])` 改为 `Box(low=-1, high=1, shape=(max_n, 2))`
  - dim 0 (control_raw)：> 0 → DESCEND, ≤ 0 → CIRCLE
  - dim 1 (speed_raw)：缩放 [-1,1] → [0.3, 1.3] 环速系数（仅 CIRCLE 生效）
- [x] `uav.py`：CIRCLE speed_factor clip 范围从 [0.7, 1.3] 扩展至 [0.3, 1.3]

### 3. 文档更新

- [x] `design_spec.md`：更新 UAVManager 初始分布描述 + `_find_safe_angle()` 方法
- [x] `technical_spec.md`：更新动作空间为 `Box(max_n, 2)` 描述
- [x] `requirements.md`：更新低层决策动作表 + Per-UAV 共享策略细节
- [x] `execution_plan.md`：新增 3b5.8（初始间距）+ 3b5.9（CIRCLE 调速）任务

## 关键发现

1. **Speed control 设计**：用户明确指出动作空间应该是二元离散选择 + 连续速度参数，而非 4 个离散选项。这与 DESCEND 的连续参数模式一致
